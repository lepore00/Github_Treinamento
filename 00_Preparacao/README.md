Preparacao_Git_GitHub

Objetivo
Preparar o ambiente de desenvolvimento para aprender Git e GitHub no Windows usando o VS Code.

Ferramentas instaladas
- Git para Windows
- Visual Studio Code
- Conta no GitHub

Configuracoes realizadas
- Nome e e-mail configurados no Git.
- VS Code definido como editor do Git.
- Ajuste de quebras de linha para Windows.
- Repositorio clonado e aberto no VS Code.
- Repositorio verificado com git status.

Resultado
A branch main esta sincronizada com origin/main e o diretorio de trabalho esta limpo.
