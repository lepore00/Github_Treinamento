# Git_show

## Objetivo
Aprender a examinar os detalhes de um commit.

## Comandos
- `git show`: mostra detalhes e alterações do commit mais recente.
- `git show --stat`: mostra um resumo dos arquivos alterados.
- `git show <hash>`: mostra um commit específico.

## Observacao
O hash identifica cada commit. Para consultar um commit anterior, copie seu hash de `git log`.
