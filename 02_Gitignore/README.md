# Gitignore

## Objetivo
Aprender a impedir que arquivos temporários sejam incluídos no controle de versão.

## Como funciona
O arquivo `.gitignore`, na raiz do repositório, contém padrões que indicam ao Git quais arquivos ou pastas ignorar.

## Exemplo
O padrão `*.tmp` ignora arquivos com a extensão `.tmp`.

## Observacao
O `.gitignore` não deixa de acompanhar arquivos que já estão sendo rastreados pelo Git.
