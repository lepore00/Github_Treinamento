## Objetivo

Aprender o fluxo de trabalho do GitHub Flow usando branches e Pull Requests.

## Etapas do fluxo

- Criar uma branch para uma alteração.
- Fazer as alterações e registrá-las em commits.
- Publicar a branch no GitHub.
- Abrir um Pull Request para revisar e propor a integração das alterações à main.
- Após a revisão, integrar as alterações e excluir a branch concluída.

## Nesta aula

Criei a branch GitHub_Flow, documentei o aprendizado e abri um Pull Request para propor a alteração à main.
