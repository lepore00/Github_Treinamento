# Branches

## Objetivo
Aprender a criar e alternar entre branches no Git.

## O que e uma branch
Uma branch e uma linha de desenvolvimento separada. Ela permite trabalhar em mudancas sem alterar diretamente a branch principal.

## Comandos
- `git branch`: lista as branches locais.
- `git branch <nome>`: cria uma branch.
- `git switch <nome>`: muda para uma branch.
- `git switch -c <nome>`: cria e muda para uma branch.

## Observacao
