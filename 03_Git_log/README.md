# Git_log

## Objetivo
Aprender a consultar o histórico de commits de um repositório.

## Comandos
- `git log`: mostra o histórico completo.
- `git log --oneline`: mostra uma linha por commit.
- `git log -n 3`: mostra os 3 últimos commits.
- `git log --stat`: mostra os arquivos alterados em cada commit.
- `git log --oneline --graph`: mostra o histórico em formato de linha.

## Como ler um commit
- Hash: identificador único do commit.
- HEAD: posição atual.
- Author: autor do commit.
- Date: data e hora do commit.
- Mensagem: descrição do que foi alterado.

## Observacao
Para sair da tela do histórico, pressione `q`.
